Wizard A edge provenance — what ships today vs. what the evidence thesis requires

Wizard A fabricates causal edges from static arc templates and writes them with an author-typed confidence. Every downstream surface renders and narrates those edges identically to evidence-backed ones. The left panel traces that path; the right shows the target design, where warrant is declared at write time and no surface can lose it.

Today

Provenance exists in the row, and dies before the surface

Template plausibility is laundered into computed confidence, then flattened by three independent consumers that each ignore source_platform.

!Net effect

A template-fabricated 0.80 and a genuinely evidence-backed 0.80 render identically, narrate identically, and are indistinguishable to the person being asked to act on them. The first question an audit function asks is not “what does the graph show” — it is “how do you know that edge is real.”

Target

Warrant is declared at write time and cannot be dropped downstream

One constructor stamps the tier; the surfaces mark rather than hide; the honesty check leaves the diagram and becomes a number.

Inputs, separated by warrant class
observed Logged event with resolvable source_ref + timestamp
asserted signal_edges.csv — a human said so
inferred ARC_TEMPLATES · LLM · lag-correlation
unknown Legacy rows with no source — never defaults to observed
A CSM typing “champion left → renewal risk” is a human inference, not an observation. Collapsing it into the top tier launders opinion into evidence — invisibly.
EdgeFactory() — the only sanctioned constructor
  • evidence_tier NOT NULL, persisted — asserted by the writer that knows its own warrant, never derived at read time by a consumer that is guessing
  • method named explicitly: template | llm | correlation
  • Inferred edges write confidence = NULL — not clamped. Nothing was computed, so no number is emitted
  • template_plausibility carried separately; never lands in a field named confidence
✓ Regression-proof by construction. A new edge source cannot silently inherit the wrong tier — the DB constraint forces it to declare one.
ContextEdge persisted with provenance
Invariant I3′ extended from nodes to edges — unearned-confidence clamp plus the existing structured event=unearned_confidence_clamp log line for ops visibility.
get_context_graph_mermaid
Always show, never hide. Dashed + gray, with (inferred) in the label text so it survives a screenshot. Graph-level banner: “0 observed edges — all 23 template-inferred.”
get_causal_chain
evidence_tier per hop, plus a pre-composed assertion string. Top-level chain_warrant: partially_inferred makes the caveat unskippable.
get_graph_summary
Evidence Density = observed ÷ total causal edges, as a named percentage — plus the observed / asserted / inferred split.
System-prompt rule — belt & braces, not the control
A prompt-layer guardrail is the weakest tier available, and IMDA's own May 2026 update ranks structural and rule-based controls above it. Keep the line; never let it be the mechanism.

Regression guard
Golden case — provision a customer with zero uploaded signal edges, then assert evidence_density == 0 and that no surface renders an unmarked causal edge.
✓Net effect

Warrant travels with the edge from constructor to diagram to narration. The honesty check stops depending on a reader noticing a dash style and becomes a number a CRO or auditor can be handed — one the product publishes about itself.

The four design rules the target state encodes

Each one is a direct response to a way the current path fails.

Write-time assertion > read-time derivation
source_platform records which system wrote the row, not what warrant it has. Deriving tier at read time reproduces the original bug with a new field name — five call sites, five chances to forget.
NULL > clamped
A clamped 0.35 is still a number, still renders, still gets narrated as if it means something. NULL is the epistemically correct value and forces every consumer to handle absence — loudly, at dev time.
Mark, never hide
The node pattern does not port. Hiding a node is additive; hiding an edge is topological. Suppress template edges on a template-only graph and you render disconnected nodes — then someone adds an exception and the discipline erodes.
Structural > prompt-layer control
Do not ask the model to caveat — put the caveat in the payload. If the honest phrasing is the data, the narration cannot route around it.
Defect in the current path Control in the target design Boundary — input or consumer Present but non-load-bearing
